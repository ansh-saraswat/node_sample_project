Node Js Project (Use GitBash Terminal)
Step 1: Install Node.js
Check if Node.js is installed:
	node -v
	npm -v

Step 2: Create Your First Project
Create a directory:
	mkdir my-first-node-app
	cd my-first-node-app
	npm init -y		## This creates:<package.json>

Step 3: Create Your First File
	app.js
Add:
	console.log("Hello Node World!");
Run:
	node app.js
Output:
	Hello Node World!
Congratulations 🎉 You ran your first Node application.

	git init

	git add .

git remote add origin https://github.com/ansh-saraswat/node_sample_project.git

check current origin
	git remote -v
	git branch

Rename master/current branch name to main
git branch -M main

git push -u origin main

Create EC2 instance on AWS
connect EC2 instance with server
configure Node on EC2 instance 

chmod 400 node-demo-key.pem​
ssh -i node-demo-key.pem ubuntu@<EC2_PUBLIC_IP>​

​# install Node.js 22 and PM2 on the server​
sudo apt update​
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash
sudo apt install -y nodejs​
sudo npm install -g pm2​​

# create the app folder and verify​
mkdir -p ~/app​
node -v && pm2 -v​

Setup Secret in github 
Settings > Secrets and variables > Actions​ >  Manage Environment Secret >
